Explain Working with Financial Data through a progressive workflow: introduce the purpose and core API, inspect the starting data, walk through the transformation, interpret the output, and finish with a small practice challenge. ## Code direction

Always generate a runnable multi-file Python example with at least two files: main.py as the entrypoint and a separate data.csv containing daily price and volume observations in data.csv. In main.py, demonstrate working with financial data with one focused transformation and a clearly printed result. Keep main.py concise and easy to review, read data.csv with a relative path, print a deterministic result, and include a short assertion or self-check.
