# Basic Object-Oriented Design in Python

> This repository stores the canonical lesson brief used by BiteCode to generate learner-facing lesson content.

## Goal

Understand object-oriented design as grouping related data and behavior.

## Content direction

Week 35 topic: Object-oriented design essentials. Build on the previous lesson, 'Designing Reusable Utility Functions', explaining the concept through the running example: domain entities like Transaction, Ticket, LessonProgress, or ImportResult. Prepare for 'Classes as Data and Behavior Containers'. Emphasize both interview reasoning (Explain when classes help and when they add noise.) and daily coding value (Bundle data and behavior when it makes the model clearer.).

## Code direction

Model a small domain object with fields and one behavior method. Keep the code short, plain Python, with English comments only.
