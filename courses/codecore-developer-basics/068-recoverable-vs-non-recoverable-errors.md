# Recoverable vs Non-Recoverable Errors

> This repository stores the canonical lesson brief used by BiteCode to generate learner-facing lesson content.

## Goal

Distinguish between errors the program can recover from and errors that should stop processing.

## Content direction

Week 23 topic: Exception handling fundamentals. Build on the previous lesson, 'Exception Handling Strategy', explaining the concept through the running example: file parsing, record validation, and external input conversion. Prepare for 'Designing Clear Error Messages'. Emphasize both interview reasoning (Explain try/except and clear error communication.) and daily coding value (Make small programs fail clearly and recover when appropriate.).
