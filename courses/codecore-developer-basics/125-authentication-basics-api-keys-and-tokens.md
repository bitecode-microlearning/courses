# Authentication Basics: API Keys and Tokens

> This repository stores the canonical lesson brief used by BiteCode to generate learner-facing lesson content.

## Goal

Explain how API keys and tokens identify a caller and why they must be protected.

## Content direction

Week 42 topic: API design and access control basics. Build on the previous lesson, 'REST API Design Basics', explaining the concept through the running example: a small API for domain records or lesson progress. Prepare for 'Authorization vs Authentication'. Emphasize both interview reasoning (Explain REST basics, API keys/tokens, and auth vs authorization.) and daily coding value (Use credentials responsibly and reason about access failures.).

## Code direction

Show reading an API token from configuration and sending it in a header. Keep the code short, plain Python, with English comments only.
