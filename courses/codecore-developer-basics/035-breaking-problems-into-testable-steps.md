# Breaking Problems into Testable Steps

> This repository stores the canonical lesson brief used by BiteCode to generate learner-facing lesson content.

## Goal

Split a problem into small steps that can be reasoned about, tested, and changed independently.

## Content direction

Week 12 topic: Algorithmic problem solving and dry runs. Build on the previous lesson, 'Algorithmic Thinking beyond Syntax', and deepen the same weekly topic. Use the running example of a small rules-based processing problem with clear input, output, and edge cases. Prepare for 'Dry Running Algorithms with Edge Cases'. Emphasize interview reasoning (Break a problem down, state invariants, and dry-run with sample data.) and daily coding value (Design small reliable algorithms before coding the final version.).

## Code direction

Break a processing task into parse, validate, transform, and summarize steps using small helper functions. Keep the code short, plain Python, with English comments only.
