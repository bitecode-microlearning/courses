# JSON as Structured Data

> This repository stores the canonical lesson brief used by BiteCode to generate learner-facing lesson content.

## Goal

Understand JSON as structured text that maps naturally to dictionaries and lists.

## Content direction

Week 22 topic: JSON and API-shaped data. Build on the previous lesson, 'Validating CSV Input Data', explaining the concept through the running example: API payloads for users, transactions, lessons, alerts, or tickets. Prepare for 'Reading and Writing JSON'. Emphasize both interview reasoning (Read, write, and transform JSON confidently.) and daily coding value (Handle API responses and configuration-like files.).

## Code direction

Inspect a nested JSON-like payload and identify the Python types created after parsing. Keep the code short, plain Python, with English comments only.
