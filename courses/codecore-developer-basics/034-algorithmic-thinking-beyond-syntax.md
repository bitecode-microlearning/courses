# Algorithmic Thinking beyond Syntax

> This repository stores the canonical lesson brief used by BiteCode to generate learner-facing lesson content.

## Goal

Turn a vague task into inputs, outputs, constraints, steps, and edge cases before writing code.

## Content direction

Week 12 topic: Algorithmic problem solving and dry runs. Build on the previous lesson, 'Priority Queues and heapq', and move the learner into the next core topic. Use the running example of a small rules-based processing problem with clear input, output, and edge cases. Prepare for 'Breaking Problems into Testable Steps'. Emphasize interview reasoning (Break a problem down, state invariants, and dry-run with sample data.) and daily coding value (Design small reliable algorithms before coding the final version.).

## Code direction

Start with a small rules-based processing task and write the algorithm outline before implementing the function. Keep the code short, plain Python, with English comments only.
