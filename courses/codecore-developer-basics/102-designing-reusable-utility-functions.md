# Designing Reusable Utility Functions

> This repository stores the canonical lesson brief used by BiteCode to generate learner-facing lesson content.

## Goal

Design small utility functions with clear inputs, outputs, and names.

## Content direction

Week 34 topic: Code organization. Build on the previous lesson, 'Separating Logic from Execution', explaining the concept through the running example: a small data-processing command split into focused functions. Prepare for 'Basic Object-Oriented Design in Python'. Emphasize both interview reasoning (Explain module structure and separation of concerns.) and daily coding value (Keep scripts testable and easy to reuse.).

## Code direction

Extract repeated normalization or validation logic into reusable functions. Keep the code short, plain Python, with English comments only.
