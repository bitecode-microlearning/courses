# Linear Search and Its Limits

> This repository stores the canonical lesson brief used by BiteCode to generate learner-facing lesson content.

## Goal

Use linear search when data is small, unsorted, or only searched once, and know its limits.

## Content direction

Week 13 topic: Search strategies. Build on the previous lesson, 'Dry Running Algorithms with Sample Data', explaining the concept through the running example: finding records by id, timestamp, threshold, or sorted score. Prepare for 'Binary Search and Sorted Data'. Emphasize both interview reasoning (Implement and explain linear and binary search.) and daily coding value (Choose when to scan, sort, or index data.).
