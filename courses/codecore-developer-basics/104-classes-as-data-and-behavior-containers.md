# Classes as Data and Behavior Containers

> This repository stores the canonical lesson brief used by BiteCode to generate learner-facing lesson content.

## Goal

Use classes when behavior belongs close to the data it operates on.

## Content direction

Week 35 topic: Object-oriented design essentials. Build on the previous lesson, 'Basic Object-Oriented Design in Python', explaining the concept through the running example: domain entities like Transaction, Ticket, LessonProgress, or ImportResult. Prepare for 'When Not to Use a Class'. Emphasize both interview reasoning (Explain when classes help and when they add noise.) and daily coding value (Bundle data and behavior when it makes the model clearer.).

## Code direction

Create a class that validates or summarizes its own domain record. Keep the code short, plain Python, with English comments only.
