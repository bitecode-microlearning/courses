# Reading and Writing JSON

> This repository stores the canonical lesson brief used by BiteCode to generate learner-facing lesson content.

## Goal

Use json.load, json.loads, json.dump, and json.dumps in the right situations.

## Content direction

Week 22 topic: JSON and API-shaped data. Build on the previous lesson, 'JSON as Structured Data', explaining the concept through the running example: API payloads for users, transactions, lessons, alerts, or tickets. Prepare for 'Transforming Nested JSON Data'. Emphasize both interview reasoning (Read, write, and transform JSON confidently.) and daily coding value (Handle API responses and configuration-like files.).

## Code direction

Read a small JSON file, update a safe field, and write formatted output. Keep the code short, plain Python, with English comments only.
