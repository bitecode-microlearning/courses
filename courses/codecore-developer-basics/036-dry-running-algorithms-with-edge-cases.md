# Dry Running Algorithms with Edge Cases

> This repository stores the canonical lesson brief used by BiteCode to generate learner-facing lesson content.

## Goal

Dry-run an algorithm with normal, boundary, and invalid inputs to catch logic errors early.

## Content direction

Week 12 topic: Algorithmic problem solving and dry runs. Build on the previous lesson, 'Breaking Problems into Testable Steps', and deepen the same weekly topic. Use the running example of a small rules-based processing problem with clear input, output, and edge cases. Prepare for 'Linear Search and Its Limits'. Emphasize interview reasoning (Break a problem down, state invariants, and dry-run with sample data.) and daily coding value (Design small reliable algorithms before coding the final version.).

## Code direction

Use comments or a small table to dry-run a function across three sample records: normal, boundary, and invalid. Keep the code short, plain Python, with English comments only.
