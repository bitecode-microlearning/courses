# KISS (Keep It Simple)

> This repository stores the canonical lesson brief used by BiteCode to generate learner-facing lesson content.

## Goal

Understand KISS, explain why it matters, and recognize the principle and apply it in a small, readable program.

## Content direction

Introduce KISS with its motivation, core rules, benefits, trade-offs, and warning signs. Compare a weak design with an improved design, then guide the learner through a focused refactoring and a short reflection exercise.

## Code direction

Use concise Python examples to demonstrate KISS. Start with an intentionally flawed snippet, improve it step by step, and include a runnable practice task plus a small self-check or assertion that shows the intended behavior.
