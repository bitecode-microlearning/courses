# Contributing

Thank you for helping future learners. Edit a lesson Markdown file or its course's `course.yml`, run `npm run validate`, and open a focused pull request. Keep each `sourceid` unchanged when renaming or moving a file. Do not add database IDs, learner information, secrets, generated emails, `likes`, or `views`.

For a new course, copy `courses/_course_template_`, rename it to the course `sourceid`, and follow the comments in its example files. Remove the leading underscore: underscore-prefixed folders are documentation and are never imported.

Useful contribution labels are `explanation`, `code_example`, `exercise`, `bug_fix`, `translation`, and `course_maintenance`; automation may otherwise classify the contribution as `other`.
